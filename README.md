## 🚀 Сборка и запуск

Нужен компилятор с поддержкой **C++17**. Сторонние библиотеки для текущей версии не требуются. Команды выполняются из корня репозитория.

### Windows · PowerShell · MSYS2 UCRT64

Если GCC установлен в другом месте, замените путь к компилятору.

```powershell
chcp 65001
$sources = @(Get-ChildItem src -Recurse -Filter '*.cpp' | ForEach-Object { $_.FullName })
& 'C:\msys64\ucrt64\bin\g++.exe' -std=c++17 -Wall -Wextra -Wpedantic -Wshadow -finput-charset=UTF-8 -fexec-charset=UTF-8 -Iinclude -static @sources -o night_shift.exe
if ($LASTEXITCODE -eq 0) { .\night_shift.exe }
```

Флаг `-static` позволяет запускать сборку без DLL компилятора. При сборке без него, если DLL не находятся, добавьте каталог компилятора в PATH текущего терминала:

```powershell
$env:PATH = 'C:\msys64\ucrt64\bin;' + $env:PATH
```

### Linux · GCC

```bash
g++ -std=c++17 -Wall -Wextra -Wpedantic -Wshadow -Iinclude src/*.cpp src/abilities/*.cpp src/statuses/*.cpp -o night_shift
./night_shift
```

Настройки задач VS Code в репозиторий не включены: для сборки можно использовать встроенный терминал. Команды включают все реализации обязательной части ЛР2.

### Проверки · PowerShell

Два независимых тестовых исполняемых файла проверяют базовые способности и обязательную часть ЛР2. Проверки используют `assert`, поэтому собирать их нужно без `-DNDEBUG`.

```powershell
$cxx = 'C:\msys64\ucrt64\bin\g++.exe'
$core = @(Get-ChildItem src -Recurse -Filter '*.cpp' | Where-Object { $_.Name -ne 'main.cpp' } | ForEach-Object { $_.FullName })
& $cxx -std=c++17 -Wall -Wextra -Wpedantic -Wshadow -finput-charset=UTF-8 -fexec-charset=UTF-8 -Iinclude -static tests/AbilitiesTests.cpp @core -o abilities_tests.exe
if ($LASTEXITCODE -eq 0) { .\abilities_tests.exe }
& $cxx -std=c++17 -Wall -Wextra -Wpedantic -Wshadow -finput-charset=UTF-8 -fexec-charset=UTF-8 -Iinclude -static tests/GameTests.cpp @core -o game_tests.exe
if ($LASTEXITCODE -eq 0) { .\game_tests.exe }
```

Проверены четыре способности, энергия и улучшения, опыт и несколько наград за одно действие, повторное применение врагами, все статусы и их объединение, независимость копий, клетки и удаление одного эффекта, смерть от горения, победа/поражение, прежние команды, неверный ввод и конец потока. Дополнительно проверены инвентарь только у игрока, мгновенная выдача предметов при шаге и телепортации, отсутствие выдачи гиду и врагам, независимость и однократность статусов выдачи, пределы ресурсов, расход только при успехе, усиление и его продление/истечение, повышение ранга во время усиления, отмена меню, Q и EOF. Тестовые поля могут явно отключать случайную генерацию статусов для изоляции сценариев; обычная игра всегда использует генерацию.

## 🎮 Управление

В начале игры выберите способность: **1 — лечение, 2 — телепортация, 3 — удар вокруг, 4 — дальний удар**. Для команд вводите одну английскую букву и нажимайте **Enter**. Регистр не важен. Во всех запросах работает `Q`; завершение потока корректно завершает игру.

| Команда | Действие |
| :---: | :--- |
| `W` / `A` / `S` / `D` | Шаг вверх / влево / вниз / вправо; взаимодействие с роботом в выбранной клетке |
| `E` | Завершить ход досрочно |
| `F` | Отключить станок, находясь рядом с его стороной |
| `R` | Выбрать способность по номеру из списка; для телепортации и дальнего удара затем ввести строку и столбец через пробел |
| `I` | Открыть инвентарь: 1 — ремкомплект, 2 — батарея, 3 — усилитель; 0 — вернуться без использования |
| `Q` | Выйти |

| Символ | Объект | Символ | Объект |
| :---: | :--- | :---: | :--- |
| `@` | Смотритель — игрок | `E` | Вражеский экспонат |
| `+` | Гид — союзник | `F` | Реставрационный станок |
| `#` | Непроходимая клетка | `.` | Обычный пол |
| `~` | Завалы | `?` | Скрытая клетка |

Карта подписана координатами. **Строки и столбцы нумеруются с 0.** Стоимость способностей и активные статусы роботов в обзоре отображаются текстом. Для лечения и удара вокруг координаты не запрашиваются.

В меню инвентаря показаны количество и действие всех трёх видов предметов. После выбора предмета игра возвращается к командам; неверный ввод повторяет запрос. `0` отменяет выбор без выхода, `Q` завершает игру. Текущий бонус атаки и оставшаяся длительность показаны рядом с характеристиками игрока.

### Как проходит ход

- Игрок расходует очки движения: обычный шаг стоит **1**, вход на завалы — **2**.
- Успешная обычная атака или ремонт расходуют **1 очко движения и 2 энергии**.
- Способности расходуют только энергию, доступны при нуле движения и сами не завершают ход. Повторять их можно, пока хватает энергии и выполняются условия применения.
- Предметы не расходуют движение или энергию и не завершают ход. Перегрузка их не отменяет. При отказе предмет остаётся в инвентаре.
- Когда движение исчерпано или введена `E`, действуют компьютерные роботы.
- В конце цикла обрабатываются статусы каждого робота: горение наносит урон, длительности уменьшаются, завершившиеся статусы удаляются. Затем выжившим восстанавливается до **3 энергии**. Погибшие освобождают клетки.
- Если игрок выжил, станок при наступлении срока пытается создать врага. Новый робот начнёт действовать со следующего цикла. Игроку обновляется движение и начинается следующий ход.
- В начале собственного хода робота обновляется движение и вызываются обработчики начала хода его статусов. За каждый новый ранг игрок получает отдельный выбор; если действие исчерпало движение, ход врагов откладывается до завершения выборов.

Гид остаётся у старта и ремонтирует стоящего рядом игрока. Враги, включая заводских, случайно получают лечение или телепортацию. Раненый враг повторяет лечение до полного здоровья или недостатка энергии; телепортации повторяются только на клетки строго ближе к видимому игроку и прекращаются рядом с ним. Каждое успешное применение расходует положительную энергию. Затем враг выполняет обычные действия: атакует соседа или выбирает свободный соседний шаг, уменьшающий расстояние. Полный поиск кратчайшего пути не реализован.

Роботы хранятся в поле по значению и перемещаются без копирования. Способностями и статусами они владеют через `unique_ptr`; изменяемые объекты не разделяются между роботами. Статус клетки клонируется при наложении. ID соответствует индексу вектора и не меняется после гибели других роботов. Клетка хранит ID, а координаты хранит поле. Общий механизм урона находится в Robot, согласованное перемещение и эффекты клеток — в Field. Только робот игрока с ID 0 получает `unique_ptr<Inventory>`; у гида и врагов объекта Inventory нет. Эти классы, способности, статусы и предметы не выполняют ввод или вывод.

## 🧩 Лабораторная работа №2

> Обязательная часть со способностями и статусами и дополнительный инвентарь реализованы и проверены. Основная часть — 6 баллов; дополнительные задания — по 2 балла. Остальные дополнительные задания не реализованы. Отметки описывают реализацию, а не выставленную оценку.

### Основные требования

- [x] **Интерфейс способности:** без полей, только публичные чисто виртуальные методы; отдельные реализации четырёх способностей.

| Способность | Действие | Улучшение при повышении ранга |
| :--- | :--- | :--- |
| Удар вокруг | Урон всем другим роботам в радиусе 1 клетки, включая союзников | Увеличение радиуса |
| Дальний удар | Урон одному выбранному роботу в радиусе 3 клеток | Увеличение урона |
| Лечение | Фиксированное восстановление здоровья применяющего робота | Увеличение лечения |
| Телепортация | Переход на выбранную свободную проходимую клетку в радиусе 5 клеток | Снижение стоимости энергии |

- [x] Каждая способность требует энергию; число применений за ход ограничено наличием энергии.
- [x] В начале игры игрок выбирает одну начальную способность из четырёх.
- [x] Враги случайно получают лечение или телепортацию.
- [x] При каждом повышении ранга игрок выбирает отсутствующую способность либо улучшение имеющейся; несколько повышений дают несколько выборов.
- [x] **Интерфейс статуса:** роботы хранят, объединяют и обрабатывают четыре отдельных класса статусов.

| Статус | Действие и снятие | Повторное наложение |
| :--- | :--- | :--- |
| Замедление | Запрещает передвижение на один ход; снимается в конце хода | Увеличивает длительность |
| Перегрузка | Отменяет попытку применить способность и снимается; способность не активируется | Работает как одна перегрузка |
| Горение | Наносит урон несколько ходов; длительность задаётся конструктором | Продлевает длительность |
| Щит | Блокирует фиксированное количество урона; при уроне больше значения щита снимается, превышение наносится здоровью | Увеличивает количество блокируемого урона |

- [x] **Статусы клеток:** проходимая клетка при генерации получает 0–2 статуса с вероятностями 70%, 25%, 5%. Стены и станок не содержат эффектов.
- [x] При шаге и телепортации все статусы клетки накладываются на робота независимыми копиями, после чего один случайный статус клетки удаляется. Начальное размещение и появление из станка не считаются наступанием.

### Параметры и принятые правила

| Способность | Энергия | Эффект | Улучшение |
| :--- | :---: | :--- | :--- |
| Лечение | 3 | 20 здоровья, не выше максимума | +10 здоровья |
| Телепортация | 5 | Манхэттенское расстояние до 5, без проверки пути | −1 энергии, минимум 1 |
| Удар вокруг | 4 | 15 урона, начальный радиус 1 | +1 к радиусу |
| Дальний удар | 3 | 20 урона, радиус 3, без проверки пути | +10 урона |

Оба удара могут повреждать союзников; использующий робот исключён из целей. Удар вокруг без целей возвращает отказ без расхода энергии. За уничтоженного противника начисляется 20 опыта через общий механизм, как при обычной атаке; за союзника опыта нет. Лечение при полном здоровье возвращает отказ без расхода энергии. Величины улучшений насыщаются на `INT_MAX`; предельное улучшение не расходует награду и требует другого выбора.

Замедление запрещает шаг и телепортацию, но не обычное взаимодействие, лечение или удары. Полученное посреди хода замедление действует сразу и сохраняется до конца следующего полного собственного хода: обработка конца текущего цикла не снимает его преждевременно. Повторное наложение добавляет один ход.

Перегрузка отменяет следующую попытку применения выбранной способности до проверки цели и энергии, снимается и не расходует энергию. Несколько перегрузок объединяются в одну. Это предусмотренное исключение из правила «при отказе состояние не меняется».

Горение с клетки длится 3 цикла и наносит по 5 урона в конце цикла; повторное наложение складывает длительности. Щит клетки имеет защиту 10. По буквальному условию урон **меньше либо равный** защите полностью блокируется, щит сохраняется с прежней величиной. Только больший урон снимает щит и наносит здоровью превышение. Повторный щит суммирует защиту. Щит одинаково обрабатывает обычные атаки, обе атакующие способности и горение. Длительности и защита также защищены от переполнения.

### Дополнительные требования

- [ ] **Эффекты способностей:** удар вокруг накладывает перегрузку; дальний удар — горение; избыточное лечение создаёт щит величиной, равной превышению максимального здоровья.
- [x] **Инвентарь только у игрока:** предметы для восстановления здоровья и энергии, временного повышения атаки; получение через отдельный статус, срабатывающий только на игроке.
- [ ] **Режимы отображения:** стандартный, подсветка врагов, непроходимых клеток и клеток со статусами; в консоли подсветка выполняется цветом.

### Инвентарь: параметры и получение

| Предмет | Действие |
| :--- | :--- |
| Ремкомплект | +30 здоровья, не выше максимального |
| Батарея | +5 энергии, не выше максимальной |
| Усилитель | +10 к обычной атаке и ремонту на 3 собственных хода игрока |

При полном здоровье ремкомплект не расходуется, при полной энергии батарея не расходуется. Мёртвый робот не может использовать предметы. Инвентарь хранит перечисление видов и массив счётчиков; отдельные классы для трёх простых предметов не нужны. Базовая атака остаётся в Robot, бонус и оставшаяся длительность хранятся в Inventory. Обычная атака и ремонт используют итоговый `Robot::attack()`, фиксированные параметры способностей не меняются. Счётчики предметов и длительности проверяются на переполнение; при невозможности продления предмет сохраняется. Итоговая атака ограничена `INT_MAX`.

Усиление действует сразу. Ход применения считается первым: сразу после использования показано 3 хода, в конце текущего собственного хода остаётся 2, в конце следующего — 1, в конце третьего — 0 и бонус снимается. Счётчик уменьшается в существующей фазе завершения хода игрока, после обработки статусов; ходы гида и врагов его не уменьшают. Повторный усилитель добавляет ещё 3 хода, сила остаётся +10. Повышение ранга меняет базовую атаку независимо от бонуса, поэтому истечение усиления не отменяет рост за ранг.

Статус ItemGrant добавлен к случайным эффектам проходимых клеток. Число статусов по-прежнему 0–2 с вероятностями 70% / 25% / 5%; среди видов статуса равновероятно выбираются четыре базовых и ItemGrant. Для ItemGrant один из трёх предметов выбирается равновероятно при создании и сохраняется в клонах. Обработчик `onApply()` выдаёт один предмет сразу и помечает копию истёкшей, поэтому она не хранится до конца хода и не выдаёт предмет повторно. `merge()` не объединяет мгновенные выдачи: два таких статуса дают два независимых предмета.

При шаге и телепортации игрока выдача работает одинаково через общий механизм клетки. Гид и враги не получают инвентарь или предмет, но после их наступания клетка всё равно теряет один случайный статус. Если ItemGrant был единственным, он удаляется и будущему игроку уже ничего не выдаст. Если на клетке два статуса и случайно удалён другой, исходный ItemGrant остаётся неизменным и может выдать предмет при последующем наступании игрока. Повторная обработка уже истёкшей копии ничего не выдаёт.
