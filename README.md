# Ночная смена

Консольная пошаговая игра для лабораторной №1 по ООП на C++17. Смотритель музея обезвреживает экспонаты и отключает реставрационный станок. Реализованы скорость и медленные клетки, обзор с памятью о местности и завод роботов 2 × 2.

## Структура

- `include/` — заголовки: Robot, Cell, Field, RobotFactory, Game, ConsoleRenderer.
- `src/` — соответствующие реализации и `main.cpp`, который создаёт Game и запускает игру.
- `.vscode/` — настройки компилятора, сборки и запуска.

## Сборка и запуск в VS Code

Откройте папку проекта целиком. Используется уже установленный GCC:
`C:/msys64/ucrt64/bin/g++.exe`.

1. `Ctrl+Shift+B` — собрать `night_shift.exe` в корне проекта.
2. «Терминал → Выполнить задачу → C++: run night_shift» — собрать и запустить игру.
3. Вводите одну английскую букву и нажимайте Enter.

Задача запуска включает `chcp 65001` перед игрой в той же сессии PowerShell. Исходники и строки компилируются в UTF-8. Заголовки находятся через `-Iinclude`. Исходники перечислены явно: тесты и старое демо в игру не включаются.

Для ручного запуска из PowerShell в папке проекта:

```powershell
chcp 65001
$env:PATH = 'C:\msys64\ucrt64\bin;' + $env:PATH
.\night_shift.exe
```

## Управление

- `W/A/S/D` + Enter — шаг или взаимодействие с соседним роботом.
- `E` — закончить ход досрочно.
- `F` — отключить соседний станок.
- `Q` — выйти.

`@` — смотритель, `E` — враг, `+` — гид, `#` — препятствие, `.` — пол,
`~` — завалы, `?` — неизвестная клетка, `F` — станок.

Обычный пол стоит 1 очко, завалы — 2. Обнаруженные стены, завалы и станок остаются видны вне обзора; роботы вне обзора скрыты. Победа — станок отключён и врагов не осталось. Нулевое здоровье смотрителя означает поражение.

Числовые настройки находятся рядом с использующими их классами: значения по умолчанию — в `Robot.h`, параметры начальной игры — в `Game.h`, параметры создаваемых врагов и единый размер станка — в `RobotFactory.h`. Координаты объектов остаются в конструкторе `Game`.

`night_shift_source.zip` содержит актуальные `include/`, `src/`, README и настройки VS Code. Тестовые файлы, исполняемые файлы, журналы и вложенные архивы не включены.
