## 🚀 Сборка и запуск

Нужен компилятор с поддержкой **C++17**. Сторонние библиотеки для текущей версии не требуются. Команды выполняются из корня репозитория.

### Windows · PowerShell · MSYS2 UCRT64

Если GCC установлен в другом месте, замените путь к компилятору.

```powershell
chcp 65001
& 'C:\msys64\ucrt64\bin\g++.exe' -std=c++17 -Wall -Wextra -Wpedantic -Wshadow -finput-charset=UTF-8 -fexec-charset=UTF-8 -Iinclude src/main.cpp src/Robot.cpp src/Cell.cpp src/Field.cpp src/RobotFactory.cpp src/Game.cpp src/ConsoleRenderer.cpp -o night_shift.exe
if ($LASTEXITCODE -eq 0) { .\night_shift.exe }
```

Если при запуске не находятся DLL компилятора, добавьте его каталог в PATH текущего терминала:

```powershell
$env:PATH = 'C:\msys64\ucrt64\bin;' + $env:PATH
```

### Linux · GCC

```bash
g++ -std=c++17 -Wall -Wextra -Wpedantic -Wshadow -Iinclude src/main.cpp src/Robot.cpp src/Cell.cpp src/Field.cpp src/RobotFactory.cpp src/Game.cpp src/ConsoleRenderer.cpp -o night_shift
./night_shift
```

Настройки задач VS Code в репозиторий не включены: для сборки можно использовать встроенный терминал. Команды выше относятся к текущей версии ЛР1.

## 🎮 Управление

Вводите одну английскую букву и нажимайте **Enter**. Регистр не важен.

| Команда | Действие |
| :---: | :--- |
| `W` / `A` / `S` / `D` | Шаг вверх / влево / вниз / вправо; взаимодействие с роботом в выбранной клетке |
| `E` | Завершить ход досрочно |
| `F` | Отключить станок, находясь рядом с его стороной |
| `Q` | Выйти |

| Символ | Объект | Символ | Объект |
| :---: | :--- | :---: | :--- |
| `@` | Смотритель — игрок | `E` | Вражеский экспонат |
| `+` | Гид — союзник | `F` | Реставрационный станок |
| `#` | Непроходимая клетка | `.` | Обычный пол |
| `~` | Завалы | `?` | Скрытая клетка |

### Как проходит ход

- Игрок расходует очки движения: обычный шаг стоит **1**, вход на завалы — **2**.
- Успешная обычная атака или ремонт расходуют **1 очко движения и 2 энергии**.
- Когда движение исчерпано или введена `E`, действуют компьютерные роботы.
- Затем станок при наступлении срока пытается создать врага. Новый робот начнёт действовать со следующего цикла.
- Если игрок выжил, живым роботам восстанавливается до **3 энергии**, игроку обновляется движение и начинается следующий ход.

Гид остаётся у старта и ремонтирует стоящего рядом игрока. Враги преследуют игрока: выбирают первый свободный соседний шаг, уменьшающий расстояние. Полный поиск кратчайшего пути не реализован.

## 🗂 Структура проекта

| Файл | Назначение |
| :--- | :--- |
| `include/Robot.h`, `src/Robot.cpp` | Характеристики робота, атака, ремонт, энергия, опыт и повышение ранга |
| `include/Cell.h`, `src/Cell.cpp` | Проходимость и стоимость клетки, ID занимающего её робота, память об обнаружении |
| `include/Field.h`, `src/Field.cpp` | Хранение поля и роботов, размещение, перемещение, взаимодействие и видимость |
| `include/RobotFactory.h`, `src/RobotFactory.cpp` | Станок размером 2 × 2, создание врагов и отключение |
| `include/Game.h`, `src/Game.cpp` | Начальная карта, команды, порядок ходов, победа и поражение |
| `include/ConsoleRenderer.h`, `src/ConsoleRenderer.cpp` | Вывод карты, характеристик и сообщений |
| `src/main.cpp` | Создание игры и запуск `run()` |

Роботы хранятся в поле по значению. ID соответствует индексу вектора и не меняется после гибели других роботов. Клетка хранит ID, а координаты хранит поле. Классы робота и поля не занимаются выводом.

## ✅ Лабораторная работа №1

> Базовая игровая механика. Основная часть — 6 баллов; каждое дополнительное требование — 2 балла. Отметки обозначают реализацию, а не выставленную оценку.

### Основные требования

- [x] **Робот:** текущее и максимальное здоровье, атака, текущая и максимальная энергия, опыт и порог следующего ранга; контролируемое изменение характеристик.
- [x] **Взаимодействие:** атака врага и лечение союзника; повышение ранга с ростом характеристик при накоплении опыта.
- [x] **Поле:** размеры через конструктор с проверкой нижней и верхней границ; конфигурация проходимых и непроходимых клеток; запрет размещения на непроходимых клетках.
- [x] **Перемещение:** проверка препятствий и взаимодействие при попытке войти в занятую роботом клетку.
- [x] **Игровой цикл:** сначала действует единственный робот игрока, затем остальные; в конце хода восстанавливается энергия и начинается следующий ход.
- [x] **Визуализация:** отдельный вывод поля и роботов; игровые сущности не зависят от отрисовки.

В базовом задании прохождением можно считать уничтожение врагов. В текущей игре с заводом дополнительно требуется отключить станок.

### Дополнительные требования

| Выполнено | Требование | Реализация |
| :---: | :--- | :--- |
| ✓ | Скорость и сложность прохождения | Запас движения зависит от скорости; обычный пол стоит 1, завалы — 2 |
| ✓ | Видимость и память местности | Содержимое вне обзора скрыто; обнаруженные непроходимые клетки и станок остаются известными |
| ✓ | Завод роботов | Занимает 2 × 2 клетки; период задаётся конструктором; создаёт врага рядом при наличии места |

В текущей версии запоминаются также завалы — это расширение требования. Обычный пол вне обзора снова скрывается, роботы отображаются только в текущем обзоре.

## 🧩 Лабораторная работа №2

> Способности и статусы. Все пункты ниже — план, пока не реализованы. Основная часть — 6 баллов; дополнительные задания — по 2 балла.

### Основные требования

- [ ] **Интерфейс способности:** без полей, только публичные чисто виртуальные методы; отдельные реализации четырёх способностей.

| Способность | Действие | Улучшение при повышении ранга |
| :--- | :--- | :--- |
| Удар вокруг | Урон всем роботам в радиусе 1 клетки | Увеличение радиуса |
| Дальний удар | Урон одному выбранному роботу в радиусе 3 клеток | Увеличение урона |
| Лечение | Фиксированное восстановление здоровья применяющего робота | Увеличение лечения |
| Телепортация | Переход на выбранную свободную проходимую клетку в радиусе 5 клеток | Снижение стоимости энергии |

- [ ] Каждая способность требует энергию; число применений за ход ограничено наличием энергии.
- [ ] В начале игры игрок выбирает одну начальную способность.
- [ ] Враги случайно получают лечение или телепортацию.
- [ ] При повышении ранга игрок выбирает новую способность, если получены не все, либо улучшение имеющейся.
- [ ] **Интерфейс статуса:** добавить роботам хранение и обработку статусов, реализовать четыре статуса.

| Статус | Действие и снятие | Повторное наложение |
| :--- | :--- | :--- |
| Замедление | Запрещает передвижение на один ход; снимается в конце хода | Увеличивает длительность |
| Перегрузка | Отменяет попытку применить способность и снимается; способность не активируется | Работает как одна перегрузка |
| Горение | Наносит урон несколько ходов; длительность задаётся конструктором | Продлевает длительность |
| Щит | Блокирует фиксированное количество урона; при уроне больше значения щита снимается, превышение наносится здоровью | Увеличивает количество блокируемого урона |

- [ ] **Статусы клеток:** при генерации клетка получает 0–2 статуса; чем их больше, тем реже появляются такие клетки.
- [ ] При наступании на клетку её статусы применяются к роботу, после чего один случайный статус клетки удаляется.

### Дополнительные требования

- [ ] **Эффекты способностей:** удар вокруг накладывает перегрузку; дальний удар — горение; избыточное лечение создаёт щит величиной, равной превышению максимального здоровья.
- [ ] **Инвентарь только у игрока:** предметы для восстановления здоровья и энергии, временного повышения атаки; получение через отдельный статус, срабатывающий только на игроке.
- [ ] **Режимы отображения:** стандартный, подсветка врагов, непроходимых клеток и клеток со статусами; в консоли подсветка выполняется цветом.
